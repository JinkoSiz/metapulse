# Деплой

Целевая конфигурация — один VPS с Docker, где `docker-compose.yml` из репозитория запускается
дословно: то, что видит ревьюер в коде, и есть то, что крутится в проде.

## Выбор хостинга

| Вариант | Цена | Комментарий |
|---|---|---|
| Hetzner Cloud CX22 | ~€4.5/мес | 2 vCPU / 4 ГБ / 40 ГБ NVMe, почасовая тарификация. Нужна международная карта или PayPal |
| Beget VPS | ~480 ₽/мес | Российские карты, Docker предустановлен. 1 ядро / 1 ГБ — минимум для этого стека |
| Selectel | от ~250 ₽/мес | Российские карты |
| Railway | $5 trial / $5 в мес | Запасной вариант: compose импортируется, но транслируется в сервисы Railway |

Бесплатные тарифы Fly.io и Koyeb в 2026 закрыты, у Render бесплатный Postgres самоуничтожается
через 30 дней и нет бесплатных воркеров — для этого сервиса они не подходят.

При 1 ГБ RAM (Beget) стоит добавить swap-файл на 2 ГБ: Postgres, Redis и два Python-процесса
в пик сборки укладываются, но без запаса.

## Порядок

```bash
# 1. на сервере
apt update && apt install -y docker.io docker-compose-plugin git
git clone <репозиторий> metapulse && cd metapulse

# 2. конфигурация
cp .env.example .env
nano .env     # ключи API, ADMIN_TOKEN, SITE_ADDRESS=metapulse.example.com

# 3. запуск
docker compose up -d --build
docker compose logs -f worker
```

`SITE_ADDRESS` — домен, на который указывает A-запись. Caddy получит сертификат Let's Encrypt
автоматически; для проверки без домена оставьте `:80`.

## После деплоя

1. **Прогрев базы.** Дождитесь нескольких часовых прогонов или нажмите «Запустить обработку»
   на `/monitor` — за один прогон добавляется 20 игр. К моменту показа в базе должно быть
   100+ игр, иначе витрина выглядит пустой.
2. **Проверьте `/monitor`**: воркер жив (heartbeat), лента событий наполняется, счётчик
   LLM-вызовов растёт.
3. **Проверьте `/llm-logs`**: файлы `YYYY-MM-DD.jsonl` не пустые.
4. **Смените `ADMIN_TOKEN`** — он защищает кнопку принудительного запуска.

## Что проверить, если сломалось

| Симптом | Причина | Что делать |
|---|---|---|
| Пустой список игр, в событиях 403 от Metacritic | Cloudflare ужесточил посадку | заполнить `MC_PROXY` резидентным прокси и перезапустить `worker` |
| Резюме не появляются | нет `ANTHROPIC_API_KEY` либо ошибка провайдера | посмотреть `/llm-logs` — там строка с `"status": "error"` и текстом ошибки |
| Летсплеи всегда с ошибкой `RequestBlocked` | датацентровый IP | заполнить `YOUTUBE_PROXY` |
| Летсплеи перестали находиться к вечеру | исчерпана дневная квота YouTube (100 поисков) | подождать сброса квоты или завести второй проект в Google Cloud |
| `/monitor` не обновляется | SSE буферизуется прокси | проверить, что запросы идут через Caddy из репозитория (`flush_interval -1`) |

## Выгрузка артефактов для сдачи

```bash
# переписка с нейросетью времён разработки
python scripts/export_ai_sessions.py

# runtime-логи LLM с сервера
docker compose cp worker:/app/logs/llm ./docs/llm-logs
```
